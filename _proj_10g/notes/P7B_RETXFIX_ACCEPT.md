## 3. 验收结论

**下行是否真恢复：否（证伪）。** 我会话同几何 A/B：Build 2 = **889.5 / 891.3 / 894.2 Mbps**（负对照，在同会话内逐字复现归档值）· r4 = **103.6–126.8 Mbps（6 跑）** = **0.12–0.14×**；缺陷臂 Build 3 = 201.7 / 挂死 / 380.7。他们会话的 189.2 是 889 的 0.21×。
